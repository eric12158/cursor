# OpenCV Calibration Tools

This set of tools allows you to perform camera calibration using OpenCV and save the results in JSON format. It supports Chessboard, Symmetric Circles Grid, and Asymmetric Circles Grid patterns.

## Tools Included

1.  **`opencv_calibration_tool.py`**: The main script to calibrate the camera from a folder of images.
2.  **`undistort_image.py`**: A helper script to undistort images using the generated JSON calibration file.

## 1. Camera Calibration (`opencv_calibration_tool.py`)

Scans a directory of images, detects the calibration pattern, computes the camera matrix and distortion coefficients, and saves the result to a JSON file.

### Usage

```bash
python opencv_calibration_tool.py --dir <IMAGE_FOLDER> [OPTIONS]
```

### Arguments

*   `--dir`: (Required) Path to the folder containing calibration images.
*   `--type`: Pattern type. Options: `circles` (default), `chessboard`, `asymmetric_circles`.
*   `--rows`: Number of rows in the pattern (default: 7).
*   `--cols`: Number of columns in the pattern (default: 7).
*   `--spacing`: Physical spacing between points/squares in mm (default: 1.5).
*   `--out`: Output JSON filename (default: `calibration_result.json`).
*   `--debug`: Directory to save images with detected corners drawn (default: `debug_output`).
*   `--show`: Display images during processing (requires GUI).

### Example

```bash
# Calibrate using a 7x7 circles grid with 1.5mm spacing
python opencv_calibration_tool.py --dir ./images --type circles --rows 7 --cols 7 --spacing 1.5 --out my_cam_calib.json
```

## 2. Undistort Image (`undistort_image.py`)

Uses the JSON file generated by the calibration tool to remove lens distortion from an image.

### Usage

```bash
python undistort_image.py --img <IMAGE_PATH> --json <JSON_FILE> [OPTIONS]
```

### Arguments

*   `--img`: (Required) Path to the image to undistort.
*   `--json`: (Required) Path to the calibration JSON file.
*   `--out`: (Optional) Output filename.

### Example

```bash
python undistort_image.py --img ./test_image.jpg --json my_cam_calib.json --out undistorted_test.jpg
```

## JSON Output Format

The output JSON file contains:

*   `camera_matrix`: 3x3 Intrinsic Matrix.
*   `dist_coeffs`: Distortion Coefficients (k1, k2, p1, p2, k3).
*   `reprojection_error`: The RMS re-projection error (lower is better).
*   `pattern_info`: Metadata about the calibration pattern used.

## Notes on Detection

*   For **Circles Grid**: The tool uses a tuned `SimpleBlobDetector` to find black circles on a white background. If your circles are white on black, or if detection fails, you may need to adjust the blob detector parameters in the code.
*   **Debug Output**: Check the `debug_output` folder to verify that the pattern was detected correctly in your images.
